# 价值与价值观互动教学

双击 `index.html` 即可在浏览器中运行。项目不需要登录、安装或联网。建议投影分辨率为 1920×1080。按 `F11` 可让浏览器全屏。

## 教学逻辑树

```text
戈壁光热电站导入动画（约 9 秒，教师也可点“下一步”）
└─ 进入故事 → 选择观察视角
   ├─ 小王：财政方案
   │  ├─ 情境 → 财政压力 → A 暂停项目
   │  │  └─ 压力暂缓 → 重启转型 → 错过积累 → 追问 → 教师揭示
   │  ├─ 情境 → 财政压力 → B 压缩投入
   │  │  └─ 项目保住 → 研发缩减 → 后续能力受影响 → 追问 → 教师揭示
   │  └─ 情境 → 财政压力 → C 论证后分阶段支持
   │     └─ 评估风险 → 继续支持 → 多种效益显现 → 追问 → 教师揭示
   ├─ 李勇：新的邀请
   │  ├─ 情境 → 职业机会 → A 离开戈壁
   │  │  └─ 收入改善 → 工作稳定 → 团队出现空缺 → 项目受影响 → 追问 → 教师揭示
   │  ├─ 情境 → 职业机会 → B 暂时留下
   │  │  └─ 继续参与 → 同时准备其他岗位 → 攻关负责人不稳 → 追问 → 教师揭示
   │  └─ 情境 → 职业机会 → C 继续攻关
   │     └─ 实验失败 → 重新计算 → 再次调试 → 技术突破 → 镜场点亮 → 追问 → 教师揭示
   └─ 两位角色都已体验 → 价值天平 → 分别讨论小王、李勇
      → 价值观概念出现 → 知识归纳
```

小王篇聚焦价值观对认识、评价和行为选择的影响；李勇篇聚焦人生价值与社会贡献。每条路线先呈现后果，再追问，最后由教师点击揭示知识。A、B、C 都可重新体验，不使用对错判定。

## 教师操作

- `下一步`：推进当前情节或逐句展示结果。
- `上一步`：返回前一个节点。
- `重新选择` / `重新体验另一种选择`：回到当前人物的三个选项。
- `返回角色`：回到双人物选择页；已体验记录会保留到本次浏览结束。
- 完成两位人物后，`进入总结` 才可用。
- 刷新页面会从故事导入重新开始。

## 修改文案和图片

`script.js` 开头的 `STORIES` 集中保存两个人物的情境、选项、结果与概念文字。`assets` 中的两张人物照片从提供的《详解.docx》提取。替换图片时保持原文件名即可。
